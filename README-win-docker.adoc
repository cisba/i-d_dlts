= Find the last metanorma working version

// https://github.com/metanorma/metanorma-ietf/issues
from the docker GUI pull the metanorma/metanorma image
compile the previous draft with the latest metanorma
if it fails to compile try previous versions
and open an issue to the metanorma team

// update the file with the last good version
$ echo <x.y.z> > last_metanorma_good_version.txt

= Usage

// edit source files if necessary 
// then update fields: docnumber published-date revdate
$ vim draft-intesigroup-dlts.adoc

// to generate a new draft version open a PowerShell 
// in the project folder and run the command:
PS> docker run --rm -v "${PWD}:/metanorma" -w /metanorma metanorma/metanorma:1.15.3 metanorma draft-intesigroup-dlts.adoc

// check result
$ git diff draft-intesigroup-dlts.txt
$ diff -W 152 -y history/draft-intesigroup-dlts-<last-ver>.txt draft-intesigroup-dlts.txt |less -S
