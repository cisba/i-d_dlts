
== Windows setup

- Install https://docs.docker.com/get-started/[docker]
- Install https://git-scm.com/install/windows[git]

Note: bash and vim are in boundle with git setup

== Find the last metanorma working version

// https://github.com/metanorma/metanorma-ietf/issues
From the docker GUI pull the metanorma/metanorma image
compile the previous draft with the latest metanorma
following the instructions in the next "Usage" section

If it fails to compile try previous metanorma versions
and https://github.com/metanorma/metanorma-ietf/issues[open an issue]
to the metanorma team

Finally, update the file with the last metanorma good version

`$ echo <x.y.z> > last_metanorma_good_version.txt`


== Usage

Edit the source files as necessary, usually updating at least fields: docnumber published-date revdate

`$ vim draft-intesigroup-dlts.adoc`

To generate a new draft version open a PowerShell in the project folder and run the command

`PS> docker run --rm -v "${PWD}:/metanorma" -w /metanorma metanorma/metanorma:1.15.3 metanorma draft-intesigroup-dlts.adoc`

Check the result

```
$ git diff draft-intesigroup-dlts.txt
$ diff -W 152 -y history/draft-intesigroup-dlts-<last-ver>.txt draft-intesigroup-dlts.txt|less -S
```
