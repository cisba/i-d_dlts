
== Linux Setup

Install https://www.metanorma.org/install/[metanorma] using snap on Linux

`$ sudo snap install metanorma`

== Windows setup

Install https://docs.docker.com/get-started/[docker]

Install https://git-scm.com/install/windows[git]

Note: bash and vim are in boundle with git setup

=== Windows Docker Metanorma Version Management

From the docker GUI pull the metanorma/metanorma image,
then compile the previous draft with the latest metanorma
following the instructions in the next "Usage" section

=== Linux Snap  Metanorma Version Management

Update metanorma release and test if iw works or fails
following the instructions in the next "Usage" section

```
$ sudo snap refresh metanorma
$ metanorma draft-intesigroup-dlts.adoc	
```

If new version fails revert to previous version and skip next section

`$ sudo snap revert metanorma`

If it works fine save it and remove old snapshot

```
$ sudo snap save metanorma
$ snap saved metanorma
$ snap forget <id> metanorma
$ snap info metanorma > snap-info-metanorma.txt
```

=== Save Last Metanorma Good Version

Update the file with the last good version

`$ echo <x.y.z> > last_metanorma_good_version.txt`

== Usage

Edit source files as necessary, usually updating at least fields: docnumber published-date revdate

`$ vim draft-intesigroup-dlts.adoc`

To generate new draft version on Linux, open a bash shell in the project folder and run the command:

`$ metanorma  draft-intesigroup-dlts.adoc`

To generate a new draft version on Windows, open a PowerShell in the project folder and run the command:

`PS> docker run --rm -v "${PWD}:/metanorma" -w /metanorma metanorma/metanorma:1.15.3 metanorma draft-intesigroup-dlts.adoc`

Note: replace 1.15.3 with the metanorma version you installed and decided to use

Check the result

```
$ git diff draft-intesigroup-dlts.txt
$ diff -W 152 -y history/draft-intesigroup-dlts-<last-ver>.txt draft-intesigroup-dlts.txt |less -S
```

Save, commit and push

```
$ cp draft-intesigroup-dlts.txt history/draft-intesigroup-dlts-<this-ver>.txt 
$ git add history/draft-intesigroup-dlts-<this-ver>.txt 
$ git commit -a
$ git push
```
